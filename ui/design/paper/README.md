# KeepPeek Paper references

The current NVR reference is [keeppeek-nvr-alpha](keeppeek-nvr-alpha/README.md), captured from
[the shared Paper file](https://app.paper.design/file/01M0B0VBH78TMTX40GCYYQ37SG/1-0).
It contains NVR boards 01–34, 45, and 46. Native viewers, Vision, and Service have separate scopes.

[keeppeek-nvr-v34](keeppeek-nvr-v34/README.md) remains the historical input to the existing visual
harness and Linux Loki baselines. Preserve its review history. A fresh Paper export does not
approve an implementation screenshot or change an existing baseline.

Read the [design decisions](keeppeek-nvr-alpha/DESIGN-DECISIONS.md) before resolving a difference.
Keep deliberate, supported functionality; record application defects in [bugs.md](../../../bugs.md).
Change the Paper source first, then export its JSX and lossless PNGs with provenance and hashes.
