# Paper Frame References

Lossless PNG exports of implementation frames live here. Paper annotation headers and handoff
prose stay outside each captured frame so Loki compares the Svelte UI with the designed UI, not
with the surrounding specification board.

Every reference image is registered in `storyboard.json` with its frame ID, viewport, byte count,
SHA-256 hash, theme, fixture, and scenario ID before it can approve a Loki reference.
