KeepPeek Desktop

Native client for an existing KeepPeek server

Connect to KeepPeek

Enter the address of a running local or remote KeepPeek server. Closing this desktop window never stops your recorder.

Use an exact origin such as http://127.0.0.1:8081 or https://nvr.example.com.

Server lifecycle and troubleshooting

  • Windows: Start KeepPeekService or run keeppeek.exe.
  • macOS: Open KeepPeek.app in /Applications to start the com.keeppeek service.
  • Remote server: Use https:// when remote HTTPS enforcement is enabled on the server. Cross-origin OIDC redirects and popup-based administrator verification require a standard browser.
  • Switch servers later: Use Connection → Switch Server (Ctrl+Shift+S on Windows, Cmd+Shift+S on macOS).
